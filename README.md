### 🛡️ [CyNER 2.0](https://github.com/Pranava-Kailash/CyNER_2.0_API)
**NLP · Transformers · FastAPI · Hugging Face · MLOps**

My MSc dissertation project: a Named Entity Recognition system for extracting cybersecurity entities from threat-intelligence text.

- Expanded the training corpus from roughly **4K to 11K+ annotated samples**
- Evaluated BERT, DeBERTa, DarkBERT, BioBERT, and spaCy using **5-fold cross-validation**
- Achieved a mean F1 of approximately **0.923 with DeBERTa-v3-base**
- Used bootstrap confidence intervals and statistical significance testing for model comparison
- Exposed the trained model through a **FastAPI REST API** for real-time inference
